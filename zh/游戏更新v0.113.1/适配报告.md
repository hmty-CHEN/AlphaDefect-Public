# 游戏 v0.113.1 适配报告（2026-11-16）

v0.113.1 是 2026-11-14 的小更新。当时只做了核对（同目录的 `核对记录.md`），训练仍用 v0.113.0。这次照《引擎模块与游戏更新适配》第六节，把引擎正式适配到 v0.113.1，作为“局面复制”无头引擎的底座（分支 `engine-clone-v0.113.1`，工作目录 `~/dev/sls2-clone113`，从 `game-v0.113.0` 的 e41ea1d 分出）。

**没有替换训练的部署**：愚者训练仍跑 v0.113.0，切不切版本由用户定。

## 摘要

- **规则变化只有一处**：拉伸（Stretch）现在会加到伶俐（Adroit）附魔的格挡上（核对记录的结论不变）。
- **引擎不用改代码**：编译 0 错误，自检兼容层 144 处全部找到，词表新增 0 项。
- **新旧引擎逐字节对拍**：六个角色各 46 局（6 局整局 + 40 场战斗），9,194 帧，不同 0。拉伸与伶俐那种局面在随机局里碰不到。
- **内容目录**：只改了 1 条（灵魂枢纽多一个图鉴动画钩子），已导出 `engine/catalog/v0.113.1/catalog.json`。

## 一、游戏文件

- 用 DepotDownloader 取 public-beta 的清单，清单号 8445808044584180628（2026-11-14 02:50）。以 v0.113.0 的下载目录为底，只补下差量 75 MB（`-validate` 只下不一致的分块）。
- 与 v0.113.0 的清单相比，变了 `SlayTheSpire2.pck`、`sts2.dll`、`sts2.xml`、`release_info.json`。三个关键文件的 SHA1 与清单一致。
- 早先核对时从 Steam 复制的 `sts2.dll` 与官方逐字节相同。`sts2.runtimeconfig.json` 是本机改过的那份（多出服务器 GC 与 CombatSolver 设置），换回官方文件，与 v0.113.0 相同。原文件备份在 `~/.local/share/sls2/game-dl/report-20261116-v0.113.1/`。
- 本地化从新的 pck 提取到 `~/.local/share/sls2/game/v0.113.1/res/localization/`，并补写 `SHA256SUMS`。与 v0.113.0 相比，本地化只改了文字与更新日志。
- `~/.local/share/sls2/game/v0.113.1/Mods/` 是早先从 Steam 复制时带进来的，引擎不加载它，没动。

## 二、编译与自检

- `engine/game_version.txt` 改为 v0.113.1 后编译：0 错误，4 条可空引用警告与 v0.113.0 相同。
- `selfcheck 3`：
  - 兼容层登记 144 处（补丁 59），找不到 0 处，另有可选的 3 处；
  - 词表 2,557 项，当前游戏应有的键 2,525 个都在，新键 0；
  - 词表里有、游戏里没有的模型键 6 个，与 v0.113.0 相同；
  - 六个角色冒烟，异常 0、卡住 0、词表外键 0。
- 冒烟的帧数两版不同，不说明规则变了：`SelfCheck` 用 `string.GetHashCode` 作随机种子，而 .NET 的字符串哈希每个进程都不同，所以冒烟本来就不可复现。

## 三、影响评估（`影响评估.md`）

内容目录：新增 0，删掉 0，改了 1 条（`MONSTER.SOUL_NEXUS` 多一个 `BeforeAnimPlayedInCompendium` 钩子，只在图鉴里用）。

引擎引用的游戏类变了 5 个，逐个对照新旧反编译源码：

| 类 | 改了什么 | 对引擎 |
|---|---|---|
| `Crusher`、`Rocket` | `Background` 由 private 改为 public | 补丁照样找到（自检通过） |
| `SoulNexus` | 加图鉴里播放动画前的回调 | 无关 |
| `EnchantmentModel` | 加虚属性 `GainsBlock`（伶俐覆盖为真） | 就是拉伸 + 伶俐的规则变化；观测不变（核对记录第“观测为什么不变”节） |
| `NKaiserCrabBossBackground` | 加公共字段 `Visuals` | 只有特效 `NImpaledArrowVfx` 用它；`ArrowCmd` 创建这个特效前先判 `NCombatRoom.Instance`，无头下为 null，不会走到 |

引擎代码不用改。仓库里写死 v0.113.0 的地方都是历史注释，或者是直播会话的文件（`python/overlay.py`），没动。
